חיבור WordPress

חיבור לאתר של הפרויקט בלבד — ללא הגדרות מודל וללא בקשות AI.

  1. מתחברים לניהול האתר (WordPress admin) ועוברים אל משתמשים (Users) ← פרופיל (Profile).
  2. גוללים למטה אל Application Passwords, נותנים שם לסיסמה (למשל: ADActive) ולוחצים על Add New Application Password.
  3. מעתיקים את הסיסמה שנוצרה ומדביקים אותה כאן למעלה.

זו אינה סיסמת הכניסה הרגילה לאתר, אלא סיסמת יישום ייעודית (Application Password).

סיסמת יישום ממשתמשים ← פרופיל ב־WordPress, לא סיסמת הכניסה הרגילה. נשמרת מוצפנת במחשב רק לאחר הצלחה ואינה נשלחת למודל.

רק לחיצה על ״בדיקת חיבור״ בודקת את פרטי המשתמש בקריאה בלבד. אין שינוי בתוכן או בהגדרות האתר.
