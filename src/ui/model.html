חיבור מודל

החיבור הקיים לא משתנה עד לבדיקה מוצלחת.

מנוי ל-ChatGPT/Claude הוא לא מפתח API — צריך להטעין קרדיט בחשבון ה-API.

אם מפתח נחשף בצ׳אט, בטלו אותו וצרו חדש אצל הספק. הזינו אותו כאן בלבד. המפתח נשמר מוצפן רק לאחר חיבור מוצלח.

רשימת המודלים תיטען אוטומטית לאחר הזנת מפתח. אין יצירת תשובה בזמן הטעינה.

רק לחיצה על ״חיבור מודל״ מאשרת בדיקת AI קצרה, שעשויה לחייב את חשבון ה־API.
